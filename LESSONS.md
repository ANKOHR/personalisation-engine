# Lessons for KOML

The fixture experiment validates deterministic selection and reconciliation against planted labels. It does not validate prospect truth, demand, response rate or subjective line quality. The assumption that a quoted specific fact is commercially useful remains untested.

Domain lesson: abstention is a useful output when evidence is absent. Keeping each line tied to the exact supplied fact and source makes manual review possible without invented familiarity.

Operating rule: separate generation from independent labels, mutate evidence to test computation, and require a real-use sample before deciding to expand. A passing synthetic test suite cannot substitute for the two-week evidence window.
